# PROMCHAT

Private, serverless group chat that runs in your browser. Chat, photos, voice notes, calls and files go straight from device to device (WebRTC, encrypted with DTLS). No accounts, nothing saved, up to 5 people.

Built by Promise ([@promiseishere](https://x.com/promiseishere)).

Open `index.html` or visit the live demo on the portfolio: https://prom-pow.vercel.app

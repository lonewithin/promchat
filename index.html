Hi there, start a private chat

Everything goes directly between your browsers. No server, no account, nothing stored.

How it works

  1. One of you taps Start chat and shows the QR (or sends the code in any app).
  2. The other taps Join chat, scans or pastes it, and sends back the reply.
  3. The first person scans or pastes the reply. Connected.

Group of up to 5: the person who started invites each friend the same way. Everyone then connects to everyone automatically.

Private by design

Encrypted end to end between browsers (WebRTC DTLS). Compare the safety code with each friend: same code = nobody in the middle.

No history, no cookies, no server. Only your theme and sound choice are remembered on this device. Panic: double-tap the PROMCHAT title to wipe everything and show a calculator.

The chat blurs when you switch apps or press a screenshot key; pictures carry a faint watermark. Phones can still screenshot web pages; these make it harder.

If it won't connect

There is no relay server by design. Some mobile networks and office/school Wi-Fi block direct connections. Try Wi-Fi on one or both phones and make new codes.
